Gushwork Web Development Assignment

This project is a responsive frontend webpage developed as part of the Gushwork frontend assignment.

The page has been built using only HTML, CSS, and JavaScript without using any external frameworks or libraries.

What’s Included

• Responsive design for desktop, tablet, and mobile screens
• Sticky navigation/header behavior on scroll
• Interactive image carousel with hover zoom effect
• Contact and enquiry forms
• Download resources section
• Semantic and accessible HTML structure
• Organized assets and readable code structure

Tech Stack

• HTML5
• CSS3
• Vanilla JavaScript

Project Structure

```plaintext
.
├── index.html
├── styles.css
├── script.js
└── assets/
```

Running the Project

You can run the project by simply opening index.html in the browser.

For development/testing, I used the VS Code Live Server extension.

Notes

• The layout and interactions were implemented based on the provided Figma design.
• Asset names were cleaned and renamed to make the project structure easier to understand and maintain.
• The project was tested across multiple screen sizes using browser developer tools.
